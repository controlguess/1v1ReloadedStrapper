# How to use
1. Download the windows copy of 1v1.LOL Reloaded from their site
2. Download and unzip our 1v1Runner and put org.sh inside of the extracted game folder
3. Open a terminal inside the game folder and run the following:
```bash
chmod +x org.sh
bash org.sh
```
4. Once everything is organized you can delete that file
5. Open the new game folder (should be called 1v1LOL-Reloaded)
6. Paste the 1v1lol-launcher.sh file into the folder
7. Enter the new game folder in a terminal and run:
```bash
chmod +x 1v1lol-launcher.sh
bash 1v1lol-launcher.sh
```

Your game should launch!
